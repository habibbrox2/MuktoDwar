২. ফিচার ও কেন

What it does

🖥️ Local only

Binds to 127.0.0.1 and refuses to start on any other address. No cloud account, no external hosting, no telemetry, no auto-updates.

🔌 OpenAI-compatible

Works unchanged with the official OpenAI SDKs, OpenCode, PHP, JavaScript and anything that speaks POST /v1/chat/completions.

🔀 Hybrid router

Combines your priority order, measured latency (EWMA), provider health, cooldown and circuit breaking.

🆓 Free-only

Providers ship disabled; models must be explicitly allowlisted and marked free by you. There is no paid fallback path in the code.

🔐 DPAPI secrets

API keys encrypted at rest with Windows DPAPI CurrentUser scope — never plaintext, fail-closed on any error.

📡 Streaming

SSE with backpressure, streamed straight through without buffering the upstream response.

৩. দ্রুত শুরু

Quick start

Install & run

npm ci          # reproducible install
npm run verify  # typecheck + tests + build
npm start       # serves on http://127.0.0.1:8787

Call the gateway

curl http://127.0.0.1:8787/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GATEWAY_TOKEN" \
  -d '{"model":"llama-3.3-70b-versatile",
       "messages":[{"role":"user","content":"Hello!"}]}'

৪. ফ্রি-অনলি নিশ্চয়তা

How free-only is enforced

  • Explicit flags. free and verified are required booleans — nothing is inferred.
  • Disabled by default. Every provider ships with enabled: false.
  • One choke point. Router.candidates() skips anything not marked free.
  • Bounded attempts. maxAttempts defaults to 3 and is capped at 5.
